    Installer UFW :

    Configurer les règles :

sudo ufw allow 80/tcp   # HTTP
sudo ufw allow 443/tcp  # HTTPS
sudo ufw allow 3306/tcp # MariaDB
sudo ufw allow 19550/tcp
sudo ufw allow 1200/tcp
sudo ufw allow 152/tcp
sudo ufw allow 20/tcp
sudo ufw allow 22/tcp
sudo ufw allow 21/tcp
sudo ufw allow ssh


sudo ufw reload


Installation de Fail2Ban

    Installer Fail2Ban :

sudo apt install fail2ban -y

    Configurer pour Apache :

sudo nano /etc/fail2ban/jail.local

    Ajouter :

[apache-badbots]
enabled = true
port    = http,https
filter  = apache-badbots
logpath = /var/log/apache2/access.log
maxretry = 3
findtime = 3600
bantime = 86400

[apache-nohome]
enabled = true
port    = http,https
filter  = apache-nohome
logpath = /var/log/apache2/access.log
maxretry = 3
findtime = 3600
bantime = 86400

[apache-dos]
enabled = true
port    = http,https
filter  = apache-dos
logpath = /var/log/apache2/access.log
maxretry = 30
findtime = 60
bantime = 600
